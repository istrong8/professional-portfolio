Ku Saga: Planet X — orbital dynamics for a fictional system

A numerical study of whether a fictional planetary system — a Sun-like star and a stellar-mass black hole in a binary, with five planets and a moon — could hold together. Newtonian N-body modeling with a velocity-Verlet implementation, REBOUND/IAS15 scenarios, and short-duration cross-checks against SciPy DOP853.

  • Python · REBOUND · SciPy · NumPy
  • Interactive offline viewer
Open the viewer ↗ Methods & limitations

The system is fictional. Short-term agreement between integrators is not evidence of long-term stability or habitability. Not peer reviewed.

In development

TLECUIL — first-order fission surface power sizer

An open, documented first-order sizing tool for surface fission power systems, scaling past 100 kWe. Python calculation engine, an interactive front end, and a LaTeX theory document written for undergraduate readers. Planned benchmarking against published studies and NASA's EZ FSP Sizer, with V&V structured toward NQA-1-style software QA.

Named for tlecuilli — Nahuatl for the three-stone hearth.

  • Python · HTML/JS · LaTeX
  • Repository not yet public

Documentation in preparation

Monte Carlo reactor physics with OpenMC

Uranium fuel pin-cell study: effective multiplication factor, flux distributions, multigroup spectra, fission reaction rates, and Monte Carlo convergence. Being written up with reproducible inputs, verification checks, and a technical report.
