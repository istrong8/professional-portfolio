# SpacePy — Space Science and Space Environment Modeling

## Overview

This directory documents independent computational exercises and scientific projects using **SpacePy**, an open-source Python library for space science data analysis and modeling.

SpacePy provides tools for investigating Earth's magnetosphere, geomagnetic coordinate systems, space weather, and radiation environments relevant to spacecraft operations.

## Research Interests

- Earth's magnetosphere and radiation belts
- Space weather and geomagnetic activity
- Geomagnetic coordinate transformations
- Solar-terrestrial interactions
- Satellite radiation environments
- Analysis of spacecraft and space science datasets
- Applications to space radiation protection and mission safety

## Software

- **Primary software:** SpacePy
- **Programming language:** Python
- **Supporting libraries:** NumPy, SciPy, Matplotlib, pandas
- **Additional tools:** Publicly available space environment datasets and models, as applicable

## Planned Computational Exercises

### Project 01 — Geomagnetic Coordinate Transformations

Use SpacePy to convert positions between supported geomagnetic and geocentric coordinate systems.

### Project 02 — Earth's Radiation Belt Environment

Investigate representative radiation-belt regions and their relationship to spacecraft trajectories using appropriate public data or models.

### Project 03 — Geomagnetic Activity Analysis

Analyze historical geomagnetic indices, create time-series visualizations, and investigate periods of elevated geomagnetic activity.

### Project 04 — Space Radiation Environment Study

Develop an introductory study of space radiation environment parameters relevant to spacecraft design and mission planning.
