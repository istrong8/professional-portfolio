# Skyfield — Astronomy, Ephemerides and Celestial Mechanics

## Overview

This directory documents planned independent computational projects using **Skyfield**, an open-source Python astronomy library.

Skyfield provides tools for computing the positions of celestial objects using astronomical ephemerides, time systems, coordinate transformations, and observer-based geometry.

## Research Interests

- Celestial mechanics and planetary motion
- Earth–Moon–Sun geometry
- Astronomical ephemerides
- Planetary positions and orbital configurations
- Lunar phases and illumination
- Solar and lunar eclipses
- Astronomical observation planning
- Applications to lunar and planetary mission environments

## Software

- **Primary software:** Skyfield
- **Programming language:** Python
- **Supporting libraries:** NumPy, Matplotlib, pandas
- **Related frameworks:** Astropy, SpiceyPy
- **Potential data sources:** Publicly available JPL planetary ephemerides

## Planned Computational Exercises

### Project 01 — Earth–Moon–Sun Position Analysis

Calculate and visualize relative positions and distances between Earth, Moon, and Sun over a selected period.

### Project 02 — Lunar Phase and Illumination Study

Investigate lunar phase geometry and illumination conditions using numerical calculations.

### Project 03 — Planetary Position Visualization

Calculate and plot the apparent positions of selected planets as observed from Earth.

### Project 04 — Astronomical Event Prediction

Investigate astronomical event timing, including conjunctions and eclipses, using ephemeris-based calculations.
