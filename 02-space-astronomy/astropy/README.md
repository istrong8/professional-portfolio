# Astropy — Astronomy and Astrophysics Computing

## Overview

This directory is dedicated to independent computational astronomy and astrophysics projects using **Astropy**, an open-source Python library for astronomical research and scientific calculations.

Astropy provides capabilities for coordinate transformations, physical units, astronomical time systems, cosmological calculations, and analysis of astronomical datasets.

## Research Interests

- Celestial coordinate systems and transformations
- Astronomical time and observation calculations
- Planetary and stellar positions
- Astronomical data analysis and visualization
- Astrophysical calculations and physical units
- FITS astronomical image processing
- Observational astronomy and scientific measurements

## Software

- **Primary software:** Astropy
- **Programming language:** Python
- **Supporting libraries:** NumPy, SciPy, Matplotlib, pandas
- **Potential extensions:** Astroquery, Photutils, and other astronomy tools

## Planned Computational Exercises

### Project 01 — Celestial Coordinate Transformations

Convert positions between equatorial, Galactic, and other astronomical coordinate systems.

### Project 02 — Astronomical Time and Observation Planning

Calculate astronomical times, coordinate-dependent observing geometry, and relevant celestial positions.

### Project 03 — FITS Image Analysis

Read and analyze publicly available astronomical FITS images and create scientific visualizations.

### Project 04 — Stellar and Galactic Data Analysis

Explore publicly available stellar catalogs and investigate astronomical parameters using Python.
