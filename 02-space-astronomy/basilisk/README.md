# Basilisk — Spacecraft Dynamics and Flight Software Simulation

## Overview

This directory documents planned independent computational projects using **Basilisk**, an open-source spacecraft simulation framework.

Basilisk integrates spacecraft dynamics, numerical simulation, sensor and actuator models, and flight software algorithms to support spacecraft design and mission analysis.

## Research Interests

- Spacecraft attitude dynamics
- Attitude determination and control systems
- Orbital dynamics and spacecraft motion
- Reaction wheels and control actuators
- Spacecraft sensor modeling
- Guidance, navigation, and control (GNC)
- Flight software simulation
- Spacecraft subsystem interactions
- Lunar and planetary mission applications

## Software

- **Primary software:** Basilisk
- **Programming languages:** Python and C/C++
- **Supporting tools:** NumPy, SciPy, Matplotlib
- **Related tools:** NASA GMAT, SpiceyPy, Astropy

## Planned Computational Exercises

### Project 01 — Spacecraft Attitude Dynamics

Simulate the rotational motion of a rigid spacecraft and investigate attitude evolution over time.

### Project 02 — Reaction Wheel Attitude Control

Develop a simplified reaction-wheel control simulation and examine spacecraft attitude stabilization.

### Project 03 — Spacecraft Sensor Modeling

Explore representative spacecraft sensor behavior and assess its influence on attitude estimation.

### Project 04 — Lunar Mission Spacecraft Dynamics

Develop a conceptual spacecraft dynamics model applicable to a lunar orbital mission.

## Project Documentation

Each completed exercise will include:

- Engineering objective and theoretical background
- Spacecraft model and assumptions
- Simulation configuration and parameters
- Python and/or C/C++ source files
- Numerical results and visualizations
- Verification and sensitivity analyses
- Limitations and future improvements
- LaTeX technical reports and compiled PDFs, as appropriate
