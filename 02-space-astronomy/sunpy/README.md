# SunPy — Solar Physics and Space Weather Research

## Overview

This directory documents planned independent computational projects using **SunPy**, an open-source Python ecosystem for solar physics data analysis.

SunPy provides tools for accessing, processing, analyzing, and visualizing solar observations, including data from space-based and ground-based solar observatories.

## Research Interests

- Solar physics and solar activity
- Solar flares and eruptive phenomena
- Solar imaging and ultraviolet observations
- Solar-terrestrial interactions
- Space weather and spacecraft environments
- Solar observation data processing
- Applications to space mission planning and radiation-environment awareness

## Software

- **Primary software:** SunPy
- **Programming language:** Python
- **Supporting libraries:** Astropy, NumPy, SciPy, Matplotlib
- **Potential data sources:** NASA Solar Dynamics Observatory (SDO) and other public solar archives

## Planned Computational Exercises

### Project 01 — Solar Image Analysis

Retrieve publicly available solar imagery and investigate image metadata, intensity distributions, and visual features.

### Project 02 — Solar Activity Time-Series Analysis

Analyze a selected solar activity dataset and create time-series visualizations.

### Project 03 — Solar Flare Event Investigation

Investigate a documented solar flare event using public observations and relevant contextual data.

### Project 04 — Solar Activity and Space Mission Considerations

Develop an introductory study exploring how solar activity information may support space mission planning and environmental assessments.
