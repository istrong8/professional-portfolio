# REBOUND — Gravitational N-Body Simulations and Celestial Mechanics

## Overview

This directory documents planned independent computational projects using **REBOUND**, an open-source N-body simulation framework for gravitational dynamics.

REBOUND enables numerical modeling of gravitational interactions between celestial bodies, including planets, moons, asteroids, and other objects in orbital systems.

## Research Interests

- Celestial mechanics and orbital dynamics
- Gravitational N-body simulations
- Planetary and satellite orbital motion
- Orbital stability and perturbation analysis
- Asteroid and small-body dynamics
- Planetary system evolution
- Numerical integration methods
- Applications to planetary and space mission environments

## Software

- **Primary software:** REBOUND
- **Programming interfaces:** Python and C
- **Supporting tools:** NumPy, SciPy, Matplotlib
- **Related frameworks:** Skyfield, Astropy, SpiceyPy

## Planned Computational Exercises

### Project 01 — Two-Body Orbital Motion

Develop a numerical simulation of a two-body gravitational system and compare the results against analytical Keplerian orbital solutions.

### Project 02 — Three-Body Gravitational Dynamics

Investigate the motion of three gravitationally interacting bodies and examine orbital behavior under selected initial conditions.

### Project 03 — Earth–Moon–Spacecraft Dynamics

Explore a simplified three-body configuration representing Earth, Moon, and a spacecraft, with clearly documented model assumptions.

### Project 04 — Orbital Stability and Numerical Integration

Investigate the influence of integration time step, numerical methods, and initial conditions on orbital accuracy and stability.

## Project Documentation
