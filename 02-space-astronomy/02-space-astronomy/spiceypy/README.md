# SpiceyPy — NASA SPICE Toolkit

## Overview

This directory documents independent computational exercises and scientific projects developed using **SpiceyPy**, a Python interface to NASA's SPICE toolkit.

SPICE provides geometric and ancillary information needed to analyze spacecraft trajectories, planetary positions, reference frames, observation geometry, and mission timing.

## Research Interests

- Spacecraft and planetary ephemerides
- Lunar and Martian orbital geometry
- Coordinate transformations and reference frames
- Earth–Moon–Sun relative positions
- Spacecraft observation geometry
- Solar illumination and eclipse analysis
- Applications to lunar surface systems

## Software

- **Primary software:** SpiceyPy
- **Underlying toolkit:** NASA NAIF SPICE
- **Programming language:** Python
- **Supporting tools:** NumPy, Matplotlib, pandas

## Planned Computational Exercises

### Project 01 — Earth–Moon–Sun Geometry
Calculate relative positions and distances between Earth, Moon, and Sun over a selected interval.

### Project 02 — Lunar Surface Illumination
Analyze solar elevation and illumination geometry at a hypothetical lunar surface location.

### Project 03 — Spacecraft Trajectory Visualization
Use publicly available SPICE kernels to reconstruct and visualize a spacecraft trajectory.
