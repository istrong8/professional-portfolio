# NASA GMAT — Spacecraft Mission Analysis and Trajectory Design

## Overview

This directory is dedicated to independent spacecraft mission analysis and orbital mechanics projects using **NASA's General Mission Analysis Tool (GMAT)**.

GMAT is an open-source space mission design and analysis system used to model spacecraft trajectories, orbital maneuvers, gravitational environments, and mission operations.

## Research Interests

- Spacecraft orbit propagation
- Earth–Moon transfer trajectories
- Lunar and Martian orbital mechanics
- Interplanetary mission design
- Orbital maneuvers and delta-v calculations
- Spacecraft mission geometry
- Orbital perturbations and gravitational effects
- Space systems engineering applications

## Software

- **Primary software:** NASA General Mission Analysis Tool (GMAT)
- **Supporting tools:** Python, NumPy, Matplotlib
- **Related frameworks:** SpiceyPy, Astropy
- **Simulation approach:** Numerical orbital propagation and mission analysis

## Planned Computational Exercises

### Project 01 — Earth Orbit Propagation

Model a spacecraft in Earth orbit, investigate orbital elements, and visualize the resulting trajectory.

### Project 02 — Earth–Moon Transfer Analysis

Develop a simplified transfer scenario between Earth orbit and lunar orbit, documenting assumptions and maneuver requirements.

### Project 03 — Lunar Orbital Mission

Model a hypothetical spacecraft in lunar orbit and investigate orbital altitude, inclination, and trajectory evolution.

### Project 04 — Interplanetary Trajectory Study

Explore a simplified Earth-to-Mars trajectory and investigate mission timing, orbital geometry, and delta-v requirements.

## Project Documentation

Each completed exercise will include:

- Mission objective and assumptions
- Spacecraft and orbital initial conditions
- Numerical propagation settings
- Simulation files and scripts
- Orbital plots and quantitative results
- Analytical comparisons or verification checks
