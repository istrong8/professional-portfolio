# Safety Engineering, Hazard Analysis & Probabilistic Risk Assessment

This section contains independent technical projects focused on engineering safety, hazard identification, accident consequence analysis, reliability engineering, and probabilistic risk assessment (PRA).

The objective is to demonstrate systematic approaches to identifying hazards, modeling accident scenarios, evaluating system reliability, and quantifying uncertainty.

## Technical Areas

- Nuclear Safety Analysis and Accident Consequences
- Probabilistic Risk Assessment (PRA)
- Fault Tree Analysis (FTA)
- Event Tree Analysis (ETA)
- Failure Modes and Effects Analysis (FMEA)
- Reliability and Availability Engineering
- Atmospheric Dispersion and Source Term Modeling
- Uncertainty Quantification and Sensitivity Analysis

## Computational Tools

Projects may include RAVEN, SCRAM, HYSPLIT, HotSpot, SALib, Python, and other applicable analysis frameworks.

## Project Documentation

Each project will describe the hazard or engineering problem, modeling assumptions, methodology, quantitative results, verification, uncertainty, limitations, and references.

All published examples will use independently developed or appropriately authorized public information.
