# OpenGATE — Radiation Transport Simulation and Dosimetry

## Overview

This directory documents independent computational exercises and scientific projects using **OpenGATE**, an open-source simulation framework based on the Geant4 particle transport toolkit.

OpenGATE provides a Python-oriented framework for modeling radiation sources, materials, particle transport, detector configurations, energy deposition, and absorbed dose.

Projects in this directory will focus on radiation physics, dosimetry, radiation detection, shielding applications, and simulation verification.

## Research Interests

- Monte Carlo radiation transport
- Radiation dosimetry and absorbed dose
- Photon and electron interactions
- Radiation source modeling
- Radiation detector simulation
- Energy deposition in materials
- Radiation shielding and attenuation
- Particle transport through complex geometries
- Simulation verification and uncertainty analysis
- Applications to nuclear and space radiation protection

## Software

- **Primary software:** OpenGATE
- **Underlying simulation toolkit:** Geant4
- **Programming language:** Python
- **Supporting libraries:** NumPy, SciPy, Matplotlib, pandas
- **Potential visualization tools:** Matplotlib and ParaView

## Verification and Validation

Projects will distinguish successful software execution from numerical verification and physical validation.

Appropriate analytical calculations, published benchmark data, or independent numerical comparisons will be used when available.

## Reproducibility

Each completed project will document the OpenGATE version, relevant Geant4 physics settings, source configuration, simulation parameters, and software dependencies.

Large simulation outputs and restricted datasets will not be included in the public repository.

## Publication Policy

Only original educational research materials, independently developed code, and publicly distributable scientific information will be published.

Employer-owned, proprietary, export-controlled, restricted-licensed, and non-public research materials will remain excluded.
