# Geant4 — Particle Transport, Radiation Shielding and Computational Physics

## Overview

This directory documents independent computational engineering and scientific projects using **Geant4**, an open-source Monte Carlo simulation toolkit for modeling the transport and interactions of particles through matter.

Geant4 provides capabilities for defining materials, geometry, particle sources, physics processes, detectors, and scoring quantities.

Projects in this directory focus on particle transport physics, radiation shielding, radiation detection, numerical simulation, and applications to nuclear and space engineering.

## Research Interests

- Monte Carlo particle transport
- Neutron and photon interactions
- Radiation shielding and attenuation
- Energy deposition and absorbed dose
- Nuclear radiation detection
- Detector geometry and response
- Particle tracking and visualization
- Material-dependent radiation interactions
- Space radiation environments
- Radiation protection for lunar and Martian systems

## Software

- **Primary software:** Geant4
- **Programming language:** C++
- **Build tools:** CMake
- **Supporting analysis:** Python, NumPy, Matplotlib
- **Visualization:** Geant4 visualization interfaces and compatible scientific visualization tools

## Project Documentation Standards

Each completed project will include, where applicable:

- Scientific or engineering objective
- Particle source specifications
- Geometry and material definitions
- Physics lists and model assumptions
- C++ source code and CMake configuration
- Macro files and simulation settings
- Computational results and scientific figures
- Statistical uncertainty and convergence checks
- Verification or validation comparisons
- Numerical limitations
- LaTeX technical reports and compiled PDFs
- Reproducibility instructions and references

## Verification and Validation

Projects will distinguish software execution checks, numerical verification, and validation against relevant experimental or published reference data.

The successful execution of a model will not be represented as evidence of physical validation.

## Reproducibility

Each study will document the Geant4 version, physics list, random seed configuration, dependencies, simulation geometry, source definitions, and analysis settings where relevant.

Large simulation outputs and restricted datasets will not be committed to GitHub.

## Publication Policy

Only independently developed code, original documentation, and publicly shareable scientific inputs and results will be included.

Original Geant4 example files will retain their applicable notices and attribution when redistributed or modified.
