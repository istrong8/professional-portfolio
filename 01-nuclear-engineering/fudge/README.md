# FUDGE — Evaluated Nuclear Data Processing and Analysis

## Overview

This directory documents independent computational nuclear engineering exercises and scientific projects using **FUDGE (For Updating Data and Generating Evaluations)**.

FUDGE is a nuclear data processing toolkit developed at Lawrence Livermore National Laboratory for working with evaluated nuclear reaction data.

Projects in this directory will focus on understanding nuclear reaction evaluations, cross-section behavior, nuclear data processing, uncertainty, and applications to reactor physics and radiation transport.

## Research Interests

- Evaluated nuclear reaction data
- Nuclear reaction cross sections
- Neutron-induced reactions
- Energy-dependent nuclear interactions
- Nuclear data formats and processing
- Nuclear data visualization
- Reaction threshold behavior
- Nuclear data comparisons
- Nuclear data uncertainty and sensitivity
- Applications to reactor physics and radiation shielding

## Software

- **Primary software:** FUDGE
- **Programming language:** Python
- **Supporting libraries:** NumPy, SciPy, pandas, Matplotlib
- **Potential nuclear data formats:** GNDS and supported evaluated nuclear data representations
- **Related tools:** NJOY, OpenMC, and other nuclear data analysis software

## Project Documentation Standards

Each completed project will include:

- Scientific objective and physical background
- Nuclear reactions and isotopes investigated
- Input nuclear data sources and evaluation versions
- Data formats and processing methodology
- Python source code and software configuration
- Numerical results and scientific visualizations
- Verification and applicable reference comparisons
- Uncertainty, assumptions, and limitations
- LaTeX technical reports and compiled PDFs
- Reproducibility instructions and references

## Reproducibility

Each project will document the FUDGE version, Python environment, nuclear data provenance, processing settings, and analysis procedures.

Large or redistribution-restricted nuclear data libraries will not be included directly in the public repository.

## Publication Policy

Only independently developed code, original documentation, and nuclear data approved for public redistribution will be published.

Employer-owned, proprietary, export-controlled, restricted-licensed, and non-public material will be excluded.
