# Nuclear Engineering Studies

## Overview

This directory organizes independently authored computational and technical research focused on independently authored nuclear engineering learning examples and technical notes. It is part of a public multidisciplinary engineering portfolio. Projects below are planned, not completed.

## Objectives

- Frame specific research and engineering questions.
- Document assumptions, quantitative models, or structured assessment methods.
- Develop reproducible technical artifacts and original calculations.
- Assess limitations, numerical verification, and uncertainty where applicable.

## Potential Methods and Tools

Projects may use Python, NumPy, SciPy, pandas, Matplotlib, LaTeX, spreadsheets, diagrams, and specialized open tools as appropriate. These are possibilities, not statements that all software has been installed or used.
